# Lista de Compra

Aplicativo Android desenvolvido em Kotlin para a matéria **Programação para Dispositivos Móveis**.

## Objetivo

O projeto tem como proposta desenvolver uma aplicação móvel relacionada à organização de uma lista de compras, aplicando conceitos de desenvolvimento Android e construção de interfaces com Jetpack Compose.

## Tecnologias utilizadas

- **Kotlin** — linguagem de programação.
- **Android Studio** — ambiente de desenvolvimento.
- **Jetpack Compose** — construção declarativa da interface.
- **Material 3** — componentes visuais da interface.
- **Gradle Kotlin DSL** — configuração e gerenciamento da compilação.

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/GabrieldeMoura9648/ListaCompra.git
   ```
2. Abra o Android Studio.
3. Selecione **Open** e escolha a pasta do projeto clonado.
4. Aguarde a sincronização do Gradle.
5. Execute o aplicativo em um emulador ou dispositivo Android compatível.

## Estrutura do projeto

- `app/` — módulo principal do aplicativo Android.
- `gradle/` — arquivos de suporte ao Gradle e ao gerenciamento de versões.
- `build.gradle.kts` e `settings.gradle.kts` — configurações de construção do projeto.

## Contexto acadêmico

Repositório desenvolvido como atividade prática da disciplina **Programação para Dispositivos Móveis**, com foco na aplicação de conceitos de desenvolvimento de aplicativos Android.
